# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Проектът съдържа само md файлове — няма код, билд и тестове. Заданието и правилата за работа са в Задание.md и се зареждат автоматично:

@Задание.md

## Как се прилагат правилата

- **Приемственост между чатовете** — в началото на всяка сесия прочети [Прогрес.md](Прогрес.md), а след всяка завършена стъпка го обнови: направено, следваща стъпка, отворени въпроси. Когато голяма задача се раздели на части, частите се записват там.
- **Тематична подредба** — по една тема на файл; всяка информация е на едно място, а другаде има само препратка към него. При добавяне, преименуване или изтриване на md файл обнови картата по-долу.
- **Независимо review** — след всяка група промени по md файловете пусни отделен subagent с чист контекст (не му подавай своите изводи). Той само чете и докладва дали всички md файлове (вкл. CLAUDE.md и Задание.md) са тематично подредени и без повтаряща се информация. Покажи находките на потребителя и поправяй едва след одобрение.
